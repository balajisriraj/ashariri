# Why evals come first
Sample essay. I believe the first thing to write for an agent is not the prompt but the evals: a list of questions and what a good answer must contain, cite or avoid.

# What a good eval suite looks like
Small and specific. A few dozen cases that cover the routes, the sources that must be found and the things the agent must never say. It runs on every change, in CI, like any other test.

# What it buys you
Evals turn prompt changes from guesswork into engineering. You can switch models, rewrite prompts or change retrieval and know within minutes what got better and what broke.
