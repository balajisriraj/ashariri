# What I'm building on the side
Sample content. I keep a few side projects going to try ideas faster than work allows. Each one is small, open source and built to be used, not just demoed.

# Ashariri
My digital twin, the one answering here. It is a LangGraph agent that answers in my voice from what I have written, cites its sources, reviews its own drafts and remembers visitors only with their consent.

# Recipe Planner
A weekly meal planner that turns what is already in the fridge into a shopping list. It uses a small agent with two tools: a pantry lookup and a recipe search.

# Reading Notes
A tool that turns my book highlights into searchable notes, so I can ask what a book said about a topic months after I read it.
